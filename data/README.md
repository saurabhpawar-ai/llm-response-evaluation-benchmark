# Benchmark Data

This directory contains the raw benchmark data and evaluated responses used in the LLM Response Evaluation Benchmark.

## Files

- `benchmark_responses.xlsx`: Raw model responses collected from the benchmark prompts.
- `benchmark_evaluations.xlsx`: Human evaluation results for the collected responses.

The benchmark contains 50 prompts evaluated across ChatGPT, Claude, and DeepSeek, producing 150 model responses.
